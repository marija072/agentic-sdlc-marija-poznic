# Agentic SDLC: Building a Software Factory

This repository contains the course project for **Agentic SDLC: Building a Software Factory** — a hands-on programme where each module produces a working AI agent that automates a phase of the software development lifecycle. By the end of the course the agents compose into an end-to-end software factory capable of taking a requirement from idea to deployed, tested code.

## Course Progress

- [ ] Module 1: Git — workflow agent
- [ ] Module 2: Software Architecture — arc42 design agent
- [ ] Module 3: Software Requirements — user story derivation agent
- [ ] Module 4: CI/CD — deployment pipeline agent
- [ ] Module 5: TDD/BDD — multi-agent test system
- [ ] Module 6: Final Project — individual kata using all agents
